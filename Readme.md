# UDC2026 中間シンポジウム＠長崎 おもてなしマップ

「長崎から考える、地域データとオープンデータの未来」シンポジウムの参加者が、会場周辺のグルメ、観光スポット、お土産店を快適に探索できるスマートフォン特化型のデジタルマップです。

## 🌟 主な機能

### 1. 情緒的なランディングページ
- **12枚の風景スライドショー**: 長崎の豊かな表情を伝える12枚の写真を全画面で表示。スムーズなクロスフェードにより情緒的な雰囲気を演出。
- **ランダム表示**: アクセスするたびに画像の順番がシャッフルされ、毎回異なる風景でユーザーを迎え入れます。
- **シンポジウム連携**: イベントの参加申し込み（Peatix）へのダイレクトリンクを設置。

### 2. インクルーシブなデジタルマップ
- **ユニバーサルデザイン**: 地図上のピンは「色」だけでなく「形状（形）」と「トーン（明るさ）」でカテゴリーを判別可能。
    - **会場**: 正方形（テラコッタレッド）
    - **グルメ**: 円形（ピーチオレンジ）
    - **観光**: 菱形（コーラルオレンジ）
    - **お土産**: 角丸四角形（モーヴピンク）
- **お気に入り機能**: 各スポットのハートマークをタップして地点を保存。保存した地点のみを抽出して表示する「お気に入りフィルター」を搭載。
- **カテゴリー＆サブカテゴリー検索**: 
    - **グルメ**: ちゃんぽん、レトロ喫茶、トルコライス、その他
    - **お土産**: カステラ、角煮まん・ぶたまん、和菓子・スイーツ、その他
- **インタラクティブな連動**: 
    - 地図上のピンと画面下のスポットカードが相互に連動。
    - 選択中のピンは**パルス（点滅）アニメーション**により現在地を強調。
- **Googleマップ連携**: 各スポットカードからワンタップで公式Webサイト確認やGoogleマップでの経路案内が可能。

## 🛠 技術仕様
- **地図基盤**: [Leaflet.js](https://leafletjs.com/)
- **タイルデータ**: [OpenStreetMap France (HOT style)](https://openstreetmap.fr/) - 視認性と温かみのある配色を採用。
- **データ形式**: 非同期通信による外部 JSON 読み込み。
- **永続化**: ローカルストレージを使用したお気に入りデータの保存。
- **開発言語**: HTML5, CSS3, JavaScript (Vanilla JS)

```
/
```

## 📝 データの更新方法
`data/spots.json` を編集するだけで、簡単にスポット情報を管理できます。

```json
{
    "id": 8,
    "name": "長崎新地中華街",
    "category": "food",
    "subcategory": "champon",
    "lat": 32.7421,
    "lng": 129.8758,
    "desc": "日本三大中華街の一つ。ちゃんぽんの名店が並びます。",
    "address": "長崎県長崎市新地町10-13"
}
```

## 🚀 運用上の特徴
- **ポータビリティ**: サーバーサイドのデータベースを必要とせず、静的ファイルの配信のみで動作するため、GitHub Pages等で即座に公開可能です。
- **オープンデータフレンドリー**: シンポジウムのテーマである「地域データ・オープンデータ」の利活用を体現した、シンプルで拡張性の高い構成。
