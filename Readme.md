# UDC2026 中間シンポジウム＠長崎 おもてなしマップ

「長崎から考える、地域データとオープンデータの未来」シンポジウムの参加者が、会場周辺のグルメ、観光スポット、お土産店を快適に探索できるスマートフォン特化型のデジタルマップです。

## 🌟 主な機能

### 1. エモいランディングページ
- **風景スライドショー**: `img` フォルダ内の風景写真を全画面で表示。Ken Burns エフェクト（ゆっくりとしたズーム）により情緒的な雰囲気を演出。
- **ランダム表示**: アクセスするたびに画像の順番がシャッフルされ、毎回異なる表情でユーザーを迎え入れます。
- **イベント連携**: シンポジウムのPeatix申し込みページへのダイレクトリンクを設置。

### 2. 高機能デジタルマップ
- **「まっぷる」思想のUI/UX**: 観光DXの視点を取り入れた、見やすく迷わない画面構成。
- **カテゴリー＆サブカテゴリー検索**: 
    - **グルメ**: ちゃんぽん、レトロ喫茶、トルコライス
    - **お土産**: カステラ、角煮まん・ぶたまん、和菓子・スイーツ
    - 各カテゴリーのテーマカラーに合わせた動的なUI。
- **マーカー＆カルーセル連動**: 地図上のピンと画面下のスポットカードが相互に連動。
- **ボトムシート詳細表示**: スポット詳細情報をスライドイン表示。Googleマップとの経路案内連携も完備。
- **GPS現在地表示**: 坂道の多い長崎の街でも安心の現在地追従機能。

## 🛠 技術仕様
- **地図基盤**: [Leaflet.js](https://leafletjs.com/)
- **タイルデータ**: [MIERUNE Mono](https://mierune.co.jp/) (OpenStreetMap contributors)
- **開発言語**: HTML5, CSS3, JavaScript (Vanilla JS)
- **アニメーション**: CSS Keyframes (フェードイン、ズーム、スライド)

## 📁 ファイル構成
```
/
├── index.html        # メイン画面・ランディングページ構造
├── css/
│   └── style.css     # デザイン・アニメーション・テーマカラー管理
├── js/
│   └── script.js    # 地図制御・フィルタリング・スライドショー制御

```

## 📝 データの更新方法
`data/spots.js` を編集するだけで、簡単にスポット情報を管理できます。

```javascript
{
    id: 9,
    name: "ツル茶ん",
    category: "food",           // カテゴリ (venue/food/sightseeing/souvenir)
    subcategory: "turkish",     // サブカテゴリ (champon/cafe/turkish/castella/kakuni/sweets)
    lat: 32.7428,
    lng: 129.8795,
    desc: "九州最古の喫茶店。元祖長崎トルコライスとミルクセーキ。",
    address: "長崎県長崎市油屋町2-47"
}
```

## 🚀 運用上の特徴
- **即時性**: サーバーサイドのデータベースを介さず、JSファイルのみで動作するため、GitHub Pages等で即座に公開可能です。
- **アクセシビリティ**: シンポジウムのテーマである「地域データ・オープンデータ」を体現した、オープンな構成となっています。
